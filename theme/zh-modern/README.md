# zh-modern

这是一个基于 Ubooquity 3 官方主题机制制作的中文美化主题。

## 覆盖范围

- 首页
- 登录页
- 书库列表页
- 书库根目录页
- 书籍详情页
- 顶栏、搜索和分页状态
- 通用样式和少量交互增强

## 安装位置

把整个 `zh-modern` 目录放到 Ubooquity 的工作目录 `themes` 下。

如果你在 LinuxServer Docker 里运行，通常可以先尝试放到：

```text
/mnt/sda4/Comics_L/config/themes/zh-modern
```

如果你的 Ubooquity 工作目录不同，就把它放到对应的 `themes/zh-modern` 目录里。

## 说明

- 这是一个前台主题，不会修改 Ubooquity 的后台管理页。
- 后台管理页如果要中文化，仍然需要浏览器自动翻译或进一步改造应用内部资源。
