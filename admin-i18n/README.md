# Ubooquity 后台汉化层

这是一个非官方的浏览器侧汉化方案，专门处理 `http://host:2203/admin` 这类后台页面。

## 适用方式

- Tampermonkey
- Violentmonkey
- 其他支持用户脚本的浏览器扩展

## 能做什么

- 把后台里常见的英文按钮、标题、提示替换成中文
- 给后台页面补一点更舒服的视觉样式
- 在页面动态刷新时自动重新翻译

## 不能做什么

- 不能改变 Ubooquity 程序本身
- 不能保证覆盖所有未来版本的新文案
- 不能替代真正的官方本地化

## 安装

1. 在浏览器里安装用户脚本扩展。
2. 新建一个脚本。
3. 把 [ubooquity-admin-i18n.user.js](./ubooquity-admin-i18n.user.js) 的内容粘进去。
4. 访问 `http://你的地址:2203/admin` 验证效果。

## 说明

这份脚本是为了“无痛可用”而设计的，优先照顾常见后台元素，不追求完全覆盖所有细枝末节。
